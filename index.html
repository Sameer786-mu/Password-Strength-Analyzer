How it works

  1. 1. Your password is hashed with SHA-1 locally (Web Crypto API).
  2. 2. Only the first 5 hash characters are sent to HIBP.
  3. 3. HIBP returns ~800+ matching suffixes (padded).
  4. 4. The remaining 35 characters are compared in your browser.
  5. 5. Nothing is stored, logged or saved.

Security Tips

Simple habits that dramatically reduce your risk online.

Length Matters

Every extra character multiplies the guesses an attacker needs. Aim for 14+ characters or a passphrase.

Password Reuse Risks

One breached site exposes every account sharing that password via credential stuffing.

Common Attacks

Brute force, dictionary attacks, credential stuffing and phishing all target weak or reused passwords.

Multi-Factor Authentication

MFA adds a second barrier — even a stolen password isn’t enough on its own.

Password Managers

Generate and store long, unique passwords for every account. Remember just one.

Data Breaches

Billions of credentials have leaked. Assume old passwords are known and rotate exposed ones.

Security Awareness

Check URLs, beware urgent messages, and keep devices and browsers updated.

About SecureCheck

SecureCheck – Password Strength Analyzer

SecureCheck is a web-based cybersecurity awareness project developed using HTML, CSS, and JavaScript. It analyzes password characteristics, identifies predictable patterns, and integrates the Have I Been Pwned Pwned Passwords API to check whether passwords have appeared in known data breaches.

The project demonstrates JavaScript programming, browser APIs, external API integration, and fundamental cybersecurity concepts.

Privacy Policy

SecureCheck never stores, logs or transmits your password. Analysis runs entirely in your browser. For breach checks, only the first 5 characters of the SHA-1 hash are sent to Have I Been Pwned. No cookies, LocalStorage or databases are used for password data.
